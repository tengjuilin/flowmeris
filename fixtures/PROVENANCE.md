All committed fixtures are third-party public test data redistributed under their original licenses.
Each directory keeps a copy of the upstream license.

| Directory | Source | Commit | License |
|---|---|---|---|

| `flowkit/gate_ref/` | Gating-ML 2.0 compliance test data (ISAC, Spidlen et al. 2015), as distributed with FlowKit | same | © 2012 ISAC: free-of-charge distribution and read-only use permitted; files must not be modified |
| `flowio/` | https://github.com/whitews/FlowIO `data/fcs_files/` | `83d28a22d42235c10d17afb017250ee208afed95` | BSD-3-Clause |
| `remote/` (not committed) | FlowKit `data/8_color_data_set/fcs_files/` — see `remote-fixtures.lock.json` | `f2159043…` | BSD-3-Clause |

`golden/` contains reference outputs generated by `tools/golden/python` (FlowKit, NumPy, SciPy and
pandas, pinned in `uv.lock`); see `golden/golden-manifest.json` for tool versions.

`golden/inputs/` is written by Flowmeris itself (`packages/export/test/golden-inputs.test.ts`): Gating-ML
and gated-event FCS files exported from the scenarios in `packages/export/test/golden-scenario.ts`, with
one manifest per scenario. They are derived from the `flowkit/` and `flowio/` files above (same licenses),
and FlowKit evaluates them to produce the other goldens. `corepack pnpm golden` rewrites both.
